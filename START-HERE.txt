FOOTBALL TRACKER - START HERE
=============================

One project that is BOTH a website and a phone app. Open the address on any
phone or computer. On a phone, add it to your home screen so it opens like
a normal app.

It starts in DEMO MODE (made-up matches) so you can see it working with no
sign-ups. Add your data key to switch to real matches.

WHAT IT DOES
- Browse matches by day with a day strip, or tap the calendar button to
  jump to any date up to about 13 months back or ahead
- Match page with 4 tabs: Ticker (goals, cards, substitutions, VAR, newest
  first), Lineups (pitch view, formations, coaches, substitutes), Stats
  (possession, shots, corners and more) and Players (ratings and stats)
- Popular leagues (Premier League, La Liga, Serie A, Bundesliga, Ligue 1,
  Champions League and more) are listed first each day, under "Top leagues"
- Search box on the Matches screen: type a club, a competition or a country
  to filter the day's matches. Days you have already opened are searched too
  ("On other days")
- Live scores, league tables, news headlines
- NO ACCOUNT NEEDED. Favorites are remembered on the device:
    * Follow teams (star button on any match page, or search by name in the
      Favorites tab) and follow single matches
    * A "Following" block at the top of the matches list and a "Mine"
      filter show your teams' games
    * Pop-up alerts while the app is open for goals, kick-off, half-time and
      full time of your teams and matches. Switch each type on or off in
      Favorites. Recent updates are listed there too
    * "Clear favorites" removes everything saved on the device
  Nothing about your favorites is stored on any server.

--- CHOOSING THE DATA SOURCE ---
The app can use one data source at a time:
  * Highlightly (recommended for now)   - set HIGHLIGHTLY_KEY in Render's Environment
  * API-Football                        - set API_KEY (only if your account is active)
  * Demo mode (made-up matches)         - leave both keys empty
If both keys exist, Highlightly is used. To force a choice, add
DATA_PROVIDER = highlightly, apifootball or demo.
Highlightly free plan: 100 requests a day. A full day of matches takes about
2 requests, each match page tab 1 request, and live scores refresh every
5 minutes for a few leagues at a time (set LIVE_POLL_SECONDS and
MAX_LIVE_LEAGUES to change this on a paid plan).
League tables: if FOOTBALL_DATA_KEY is set (free key from football-data.org),
tables of these competitions come from football-data.org, which saves
Highlightly requests: Premier League, Championship, La Liga, Serie A
(Italy and Brazil), Bundesliga, Ligue 1, Eredivisie, Primeira Liga,
Champions League, World Cup and European Championship. Every other league,
or any time football-data.org refuses, uses the main source.
Optional test pages: add DIAG_TOKEN = any secret word, then open
/api/diag/highlightly?token=YOURWORD or /api/diag/footballdata?token=YOURWORD
to check each key. Delete DIAG_TOKEN when you are done.

--- UPDATING AN EXISTING SETUP (you already did the first setup) ---
1. Unzip this folder.
2. On GitHub, open your football-tracker repository.
3. Tap "Add file" > "Upload files".
4. Drag in EVERYTHING from the unzipped folder: server.js, highlightly.js
   (new), package.json, START-HERE.txt and the "public" folder.
   (Files with the same name are replaced.)
5. Tap "Commit changes". Render notices and rebuilds by itself
   (about 2 minutes). Then close the app on your phone and open it again.
6. Optional tidy-up: the old file "store.js" is no longer used. You can
   open it on GitHub and delete it (three dots > Delete file). Leaving it
   does no harm.
7. Optional tidy-up: on Render, the DATABASE_URL setting (if you added it)
   is no longer needed.

--- FIRST-TIME SETUP ---
1. Free API-Football key (real data): https://www.api-football.com
2. Free GitHub account: https://github.com
3. Free Render account: https://render.com
4. On GitHub, make a repository and upload all these files.
5. On Render: New > Web Service > pick your repository.
     Build Command:  npm install
     Start Command:  npm start
     Instance type:  Free
6. Render > your service > Environment. Add:
     API_KEY  =  (your API-Football key)      <- switches on real matches
7. Open the address Render gives you.

--- INSTALL ON YOUR PHONE ---
Android (Chrome): menu (3 dots) > "Install and create shortcut"
iPhone (Safari):  Share button > "Add to Home Screen"

--- GOOD TO KNOW ---
- Favorites live on ONE device. A new phone starts empty, and clearing the
  app's data or uninstalling removes them. (An optional cloud backup or
  account could be added later if you want favorites on several devices.)
- The free Render plan sleeps when unused. The first open after a break
  can take about a minute.
- The free API-Football plan allows 100 requests a day. Each new day you
  open, each Lineups or Players tab, each team search and each live refresh
  uses some. The app saves requests by remembering what it already fetched,
  and once it learns which days your plan covers it stops asking for other
  days. If a day is not included in your plan, the app says so on that
  day's screen. Months of real matches need a paid API-Football plan; the
  app itself does not change.
- Alerts appear only while the app is open. Alerts when the app is closed
  (push notifications) come with the Android and iPhone store versions.
- News (optional): add NEWS_FEEDS = link to a news site's RSS feed
  (several allowed, separated by commas). The app shows only the headline,
  the source name and a link back. Check each site's terms first.
- Before the public launch: add a privacy policy page. Stores ask for one
  even when you collect very little.
